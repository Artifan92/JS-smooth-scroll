# JS-smooth-scroll

Невеликий ES-модуль без залежностей: плавний скрол до секцій сторінки з урахуванням фіксованого хедера та кнопка «вгору», яка з'являється після прокрутки.

- Один файл, без збірки й залежностей
- Працює з `data-goto` та зі звичайними якорями `href="#id"`
- Не падає, якщо на сторінці нема хедера чи кнопки «вгору»
- Оновлює адресу (`#id`), переносить фокус, враховує `prefers-reduced-motion`
- Повертає функцію для зняття всіх обробників

## Швидкий старт

Скопіюй `smoothScroll.js` у проєкт і підключи як модуль:

```html
<script type="module">
	import smoothScroll from './smoothScroll.js';

	smoothScroll('.menu__link');
</script>
```

Або в бандлері (Vite, Webpack тощо):

```js
import smoothScroll from './modules/smoothScroll.js';

window.addEventListener('DOMContentLoaded', () => {
	smoothScroll('.menu__link');
});
```

Файл має `export`, тому підключати його треба саме як модуль (`type="module"`) або через бандлер. Викликай функцію після того, як розмітка вже є в DOM.

## Розмітка

```html
<header>
	<nav>
		<a class="menu__link" data-goto=".about" href="#about">Про нас</a>
		<a class="menu__link" href="#contacts">Контакти</a>
	</nav>
</header>

<section class="about" id="about">…</section>
<section id="contacts">…</section>

<a class="pageup menu__link" href="#" data-goto="body">↑</a>
```

Звідки береться ціль скролу:

1. з `data-goto` — будь-який CSS-селектор (`.about`, `#about`, `[data-section="about"]`);
2. якщо `data-goto` нема — з `href="#id"`.

Якщо ціль не знайдено, скрипт посилання не чіпає, і воно працює як звичайне. Тому в те саме меню можна класти й зовнішні посилання.

Радимо завжди лишати справжній `href="#id"`: тоді навігація працює і без JavaScript.

## Стилі для кнопки «вгору»

Скрипт сам виставляє кнопці `opacity` (0 або 1) і `pointer-events: none`, коли вона прихована, а також перемикає клас `is-visible`. Мінімальних стилів достатньо таких:

```css
.pageup {
	position: fixed;
	right: 20px;
	bottom: 20px;
	transition: opacity 0.3s;
}
```

Якщо хочеш керувати виглядом лише через клас, використовуй `.pageup.is-visible { … }` — назву класу можна змінити опцією `visibleClass`.

## API

```js
const destroy = smoothScroll(menuSelector, options);
```

| Параметр | Тип | Опис |
| --- | --- | --- |
| `menuSelector` | `string` | CSS-селектор посилань, кліки по яких треба обробляти |
| `options` | `object` | Необов'язкові налаштування, див. нижче |

Опції:

| Опція | Тип | За замовчуванням | Опис |
| --- | --- | --- | --- |
| `headerSelector` | `string \| null` | `'header'` | Хедер, висота якого віднімається від позиції скролу. Враховується лише коли він `position: fixed` або `sticky`. `null` — не враховувати |
| `offset` | `number` | `0` | Додатковий відступ зверху, px |
| `pageUpSelector` | `string \| null` | `'.pageup'` | Кнопка «вгору». `null` — вимкнути цю частину |
| `pageUpThreshold` | `number` | `10` | Після скількох px прокрутки показувати кнопку |
| `visibleClass` | `string` | `'is-visible'` | Клас, який отримує видима кнопка |
| `updateHash` | `boolean` | `true` | Додавати `#id` цілі в адресу (через `history.pushState`) |

Повертає функцію `destroy()`, яка знімає всі обробники кліків і скролу. Корисно в односторінкових застосунках, коли меню перемальовується.

## Приклади

Додатковий відступ 20px над секцією і власний хедер:

```js
smoothScroll('.menu__link', {
	headerSelector: '.site-header',
	offset: 20,
});
```

Тільки плавний скрол, без кнопки «вгору»:

```js
smoothScroll('.menu__link', { pageUpSelector: null });
```

Тільки кнопка «вгору», без меню:

```js
smoothScroll('.pageup'); // кнопці потрібен data-goto="body" або href="#id"
```

Не міняти адресу сторінки:

```js
smoothScroll('.menu__link', { updateHash: false });
```

Перепідключення після перемальовування меню:

```js
let destroy = smoothScroll('.menu__link');

function onMenuRerender() {
	destroy();
	destroy = smoothScroll('.menu__link');
}
```

## Як це працює

- **Позиція скролу** = верх цілі відносно документа − висота хедера (якщо він `fixed`/`sticky`) − `offset`. Від'ємне значення обрізається до 0.
- **Висота хедера** читається в момент кліку, тому хедер, який змінює висоту при прокрутці чи на мобільному, враховується правильно.
- **Клік перехоплюється** (`preventDefault`) лише тоді, коли ціль знайдено.
- **Фокус** після переходу переноситься на ціль (їй додається `tabindex="-1"`, якщо атрибута не було), щоб `Tab` продовжував із секції, а не з меню.
- **Адреса** отримує `#id` цілі, якщо вона має `id`; працюють кнопка «назад» і прямі посилання на секцію.
- **`prefers-reduced-motion: reduce`** — скрол миттєвий, без анімації.
- **Кнопка «вгору»** оновлюється не частіше одного разу на кадр (`requestAnimationFrame`), слухач скролу пасивний.

## Підтримка браузерів

Сучасні браузери: орієнтовно Chrome/Edge 88+, Firefox 86+, Safari 15.4+. Обмеження задають `AbortController` у `addEventListener` та плавний `window.scrollTo`. Internet Explorer не підтримується.

## Перехід зі старої версії

Старий виклик працює без змін:

```js
smoothScroll('.menu__link');
```

Що поводиться інакше:

| Було | Стало |
| --- | --- |
| Помилка в консолі, якщо нема `.pageup` або `header` | Відсутні елементи пропускаються |
| Кожен клік по посиланню меню блокувався | Блокується лише клік із знайденою ціллю; `href="#"` без `data-goto` тепер стрибає вгору сторінки як звичайний якір |
| Висота `header` віднімалась завжди | Лише коли хедер `fixed` або `sticky` |
| Ціль тільки з `data-goto` | З `data-goto` або з `href="#id"` |
| Адреса не мінялась | Додається `#id` (вимикається через `updateHash: false`) |
| Прихована кнопка «вгору» лишалась клікабельною | Отримує `pointer-events: none` |

## Перевірка вручну

Автоматичних тестів у репозиторії поки нема. Після змін у скрипті варто пройтися по списку:

1. Клік по посиланню з `data-goto` — секція зупиняється одразу під хедером.
2. Клік по посиланню лише з `href="#id"` — те саме.
3. В адресі з'являється `#id`, кнопка «назад» повертає попередню позицію.
4. `Tab` після переходу йде по елементах секції.
5. Кнопка «вгору» з'являється після прокрутки і зникає вгорі; прихована не клікається.
6. Зовнішнє посилання в меню відкривається як звичайне.
7. На сторінці без `header` та без `.pageup` консоль чиста.
8. З увімкненим «зменшенням руху» в системі скрол миттєвий.
